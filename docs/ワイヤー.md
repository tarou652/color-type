# ワイヤーフレーム仕様（カラー診断結果サイト）

## 前提
- 対象：家族みんな（グループLINEで共有）
- 目的：服・プレゼント選びの参考にしてもらう
- 利用シーン：LINEで送られたリンクをスマホでサッと見る
- 方針：**モバイル最優先**。ファーストビュー＝結論、理論は下部に格納

内容データは同ディレクトリの `style-diagnosis.md` を参照。

---

## ページ構成（上から順）

### 1. ヘッダー（常時・控えめ）
- タイプ名を小さく表示：「ミューテッドサマー × ミューテッドオータム」
- 専門用語の説明はしない（ここでは読ませない）

### 2. 結論ブロック（ファーストビュー内に収める／アクセントカラーで強調）
スクロール0回で見える範囲に、以下だけを表示：
- 似合う色のスウォッチ（5〜6色程度。ベストカラー14色から代表色を抜粋）
- 一言：似合う系統 →「くすみ系全般」
- 一言：避ける配色 →「白・黒・赤のハイコントラストは避ける」
- 一言：スーツの色 →「グレー系／柔らかいネイビー」

### 3. クイックサマリーカード（2カラムグリッド）
- 顔タイプの一言サマリー：「カジュアル×きれいめミックス」
- 骨格の一言サマリー：「重心は上に」

ここまでが「結論エリア」。ここから下は任意で読む理論パート。

---

### 4. 理論セクション（アコーディオン／初期状態は全て閉じる）

タップで開閉。同時に複数開いてもよい。

1. **カラー診断の理論・全パレット**
   - ファースト/セカンドタイプの説明
   - ベストカラー14色の一覧（表）
   - コーディネートの原則
   - スーツ・シャツ襟・ヘアカラーの詳細
2. **顔タイプ診断の詳細**
   - 得意／苦手の比較
   - おすすめブランド
   - メガネ・髪型・眉毛
3. **骨格診断の詳細**
   - トップス／ボトムス／スーツ／小物
4. **香水・その他**

各見出しの本文は `style-diagnosis.md` の対応セクションをそのまま流し込む想定。

---

## インタラクション仕様
- 理論4項目：アコーディオン開閉（デフォルト閉）
- ページ内ナビゲーションは不要（1本道スクロール想定。前バージョンのタブnavは廃止）
- 結論ブロックのみ、アクセントカラー（他は白/グレーベースの落ち着いたトーン）

## Claude Codeへの渡し方
1. この `wireframe.md` と `style-diagnosis.md` をNuxtプロジェクトの `docs/` などに置く
2. Claude Codeのセッションで両ファイルを指定し、「このワイヤーと内容データを元にトップページを実装して」と依頼する
3. 参考イメージが欲しい場合は、先ほどのモックアップをスクリーンショットして同じフォルダに入れておくとより伝わりやすい
